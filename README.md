# Keerthi Vasan — Developer Portfolio

Responsive client-facing portfolio website using separate HTML, CSS, and JavaScript files.

## Files
- `index.html` — page structure and content
- `css/style.css` — responsive styling
- `js/script.js` — mobile navigation and subtle reveal animations

## Preview locally
Open `index.html` in your browser.

## Before sharing with clients
- Verify job titles, dates, years of experience, and project descriptions against your final resume.
- The project cards summarize professional experience and are not represented as public demos.
- Replace or add a real company/profile logo if you have one. The current `K` monogram is a text logo.
- For a public URL, upload the folder to GitHub Pages, Netlify, or another static hosting provider.
